Which estimator

Find the task you have, then pick the estimator. The parameters are the Python names; the Rust, WASM and C names are the same in snake case or camel case, and the bindings' READMEs have the rest. Defaults are the ones in the Python signatures.

Pick by task

I want toUseNotes
Group points, with a known number of groupsKMeansEuclidean distance. Needs n_clusters.
Group points, find the number of groups and mark outliersDBSCAN or HDBSCANNoise points get label -1.
Reduce dimensions for display or for a modelPCACentres the data. Use TruncatedSVD for sparse data.
Factor non-negative data into partsNMFFrobenius loss, multiplicative updates. Input must be non-negative.
Predict a number from numbers, with no regularisationRidge with a small alphaClosed form.
Predict a number and drop irrelevant inputsLassoCoordinate descent. Sets some coefficients to exactly zero.
Predict a number with L1 and L2 penalties togetherElasticNetl1_ratio picks the mix.
Classify, with probabilitiesLogisticRegressionL2 penalty, Newton iterations. C is the inverse strength of the penalty. The Rust crate also has a multinomial model; check docs/usage.md for what each binding exposes.
Classify or regress with trees you can readDecisionTreeClassifier, DecisionTreeRegressorGini or entropy for classification. Has feature_importances_.
Get the most accuracy from trees on tabular dataRandomForestClassifier, RandomForestRegressor, GradientBoostingRegressorForests average trees. Boosting fits them in sequence with learning_rate.
Classify with a very small, fast ensembleStumpForestBagged depth-one trees with majority vote.
Prepare features before a modelStandardScaler, MinMaxScaler, RobustScalerFit on training data only.
Encode categories as numbersOneHotEncoder, OrdinalEncoderAn unseen category at transform time is an error.
Fill missing valuesSimpleImputerstrategy is "mean", "median", "most_frequent" or "constant".
