Quickstart

Nothing is published to a registry yet, so each example starts from a checkout of the repository. Every example clusters the same eight points into two groups.

Rust

In a crate that depends on tpt-ml-proven by path:

use tpt_ml_proven::prelude::*;

let data = [0.0, 0.0, 0.1, 0.0, 10.0, 10.0, 10.1, 10.0];
let x = DenseView::new(&data, 4, 2).unwrap();
let mut km = KMeans::<f64>::new(2).with_seed(1);
UnsupervisedEstimator::fit(&mut km, x).unwrap();
let labels = Predictor::predict(&km, DenseView::new(&data, 4, 2).unwrap()).unwrap();

The worked examples are in crates/tpt-ml-proven/examples/: save_and_load and cross_validate. Run them with cargo run -p tpt-ml-proven --example save_and_load.

Python

Build and install into a virtual environment, with maturin develop --release run in ffi/python. Inputs can be NumPy arrays, lists of rows, pandas or polars frames.

from tpt_ml_proven import KMeans

X = [[0.0, 0.0], [0.1, 0.0], [10.0, 10.0], [10.1, 10.0]]
labels = KMeans(2, seed=1).fit_predict(X)

The tour notebook, ffi/python/examples/tour.ipynb, covers clustering, save and load, a scikit-learn pipeline, trees and forests, with its outputs already run.

JavaScript (WebAssembly)

Build the packages with node scripts/build.mjs in ffi/wasm. Constructors take an options object.

const { KMeansModel } = require("./pkg/tpt_ml_proven_wasm.js");

const km = new KMeansModel({ nClusters: 2, seed: 1 });
km.fit(new Float64Array([0, 0, 0.1, 0, 10, 10, 10.1, 10]), 2);   // flat row-major data, then the column count
const labels = km.labels;   // a getter, not a method

The browser demo is ffi/wasm/demo/index.html. It loads the web package. It has not yet been run in a browser; see the status note in todo.md.

Go

The Go package uses cgo over the C library. Build the library first with cargo build --release --manifest-path ffi/c/Cargo.toml, then use the module at github.com/tpt-solutions/tpt-ml-proven/ffi/go (Go 1.21 or later).

x := [][]float64{{0, 0}, {0.1, 0}, {10, 10}, {10.1, 10}}
km, err := mlproven.NewKMeans(2, mlproven.WithSeed(1))
if err != nil { log.Fatal(err) }
defer km.Close()
if err := km.Fit(x); err != nil { log.Fatal(err) }
labels, err := km.Labels()

C

The C ABI is in ffi/c. examples/main.c is a complete program that is compiled and run in CI. Install to a prefix with sh install.sh <prefix>, then build against it with pkg-config --cflags --libs tpt-ml-proven.
