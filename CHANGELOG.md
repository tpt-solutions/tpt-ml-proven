# Changelog

All notable changes to this project are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- `tpt-ml-proven-core`: estimator traits (`SupervisedEstimator`, `UnsupervisedEstimator`,
  `Predictor`, `Transformer`), dense and CSR input views, the `Float` trait for
  `f32`/`f64`, the shared `Error` type, and the `requires!`/`ensures!`/`static_require!`
  contract macros. Usable under `no_std` + `alloc`.
- `tpt-ml-proven-clustering`: `KMeans` (Lloyd's algorithm) with k-means++ and random
  initialisation, seeded and reproducible, dense and sparse input, empty-cluster
  handling, and an optional multi-threaded (`parallel`) path whose results match the
  sequential path exactly.
- `tpt-ml-proven-decomposition`: `Pca` with explained variance and ratio,
  `fit`/`transform`/`inverse_transform`/`fit_transform`, and a deterministic sign
  convention. Eigendecomposition is a Jacobi solver written in the crate.
- Contracts in `docs/contracts/` for the toy estimators, KMeans and PCA, with runtime
  checks for each clause.
- `tools/tptc-verify`: a dev-only verifier that solver-checks linear contract clauses
  with `tpt-solver`, confirms counterexamples before reporting them, and checks linkage.
- scikit-learn parity tests (1e-9) on committed fixtures, generated by a pinned script.
- Benchmark harness for KMeans on 1M × 50 `f32`, with scikit-learn comparison.
- Python bindings (`ffi/python`): `KMeans` and `PCA`, `abi3` wheels for Python 3.9+.
- WebAssembly bindings (`ffi/wasm`): `KMeansModel` and `PcaModel`.
- C ABI (`ffi/c`) with a cbindgen-generated header, for the planned Go binding.

### Known limitations

- `tools/tptc-verify` depends on the `tpt-solver` commit `b50487d`, which fixes the
  strict-inequality and model-checking bugs found during verification.
- KMeans is about 1.9× slower than scikit-learn on one thread and about 1.7× slower
  with all cores on the benchmark problem (see `docs/benchmarks.md`).
- The Go binding is not yet written.
- Linux and macOS wheels, and clean-VM installs, are untested until CI runs on GitHub.
