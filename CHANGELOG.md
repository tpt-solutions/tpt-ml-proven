## [Unreleased]

### Added

#### Algorithms (Phases 8 and 10)

- DBSCAN, HDBSCAN, TruncatedSVD, NMF, Ridge, Lasso, ElasticNet, binary and multinomial
  logistic regression, the scalers, encoders and imputers, a stump forest, and the tree models
  (a CART regressor and gradient boosting). Each has runtime contract checks and a `.tptc`
  contract where the property is structural.
- Gradient-boosting predictions match scikit-learn 1.9.0 to 1e-9 on a committed fixture.

#### Model files (Phase 9)

- The version 1 on-disk format, specified in [docs/model-format.md](docs/model-format.md):
  magic header, format version, model kind, little-endian fields, and an FNV-1a checksum.
  Readers refuse newer versions and check each model's invariants on load.
- `to_bytes` and `from_bytes` for every model in the workspace.
- Golden version 1 files for Ridge, KMeans and PCA, which their tests load on every run.

#### Contracts and verification

- Contracts in `docs/contracts/` for the toy estimators, KMeans, PCA, and the Phase 8 and 10
  algorithms, with runtime checks for each clause.
- `tools/tptc-verify`: a dev-only verifier that solver-checks linear contract clauses with
  `tpt-solver`, confirms counterexamples before reporting them, and checks linkage.
- scikit-learn parity tests on committed fixtures, generated by a pinned script.

#### Bindings

- Python (`ffi/python`): KMeans, PCA and the Phase 8 estimators (except the preprocessing
  transformers and tree models). `abi3` wheels for Python 3.9+.
- WebAssembly (`ffi/wasm`): KMeans, PCA and the Phase 8 estimators.
- C ABI (`ffi/c`): KMeans, PCA and all the Phase 8 estimators, with a cbindgen-generated header.
- Go (`ffi/go`): KMeans and PCA over the C ABI, with a cgo package and tests.
- A non-blocking benchmark job and a Go job in CI.

#### Documentation (Phase 7 and 9)

- A usage guide for each binding (`docs/usage.md`), a model file format specification, and a
  static landing page (`docs/site/`).
- A Go import-path placeholder page (`docs/site/go/mlproven/`). It is not live, and `go.mod`
  is unchanged, since changing the module path would break existing users.

### Known limitations

- `tools/tptc-verify` depends on the `tpt-solver` commit `b50487d`, which fixes the
  strict-inequality and model-checking bugs found during verification.
- Linux and macOS wheels, and clean-VM installs, are untested until CI runs on GitHub. The
  CI jobs have not run on GitHub yet.
- KMeans is slower than scikit-learn (1.9× single-threaded, 1.7× on all cores), so the 2×
  speed target is not met.
- Model files are not yet exposed through any binding.
- The preprocessing transformers and the tree models are not yet exposed through any binding.
- Go's module path still points at GitHub, and prebuilt static libraries are not provided.
